# Biotex - Remisiones con máscara de contrato

Módulo para **Odoo 19 Enterprise** · Alphaqueb Consulting SAS · Proyecto Biotex (fase 1).

Remisión de salida por delegación con razón social del contrato, producto entregado vs. clave cobrada (máscara), consumo de contrato, firma y facturación agrupada

## Dependencias
`biotex_contract`, `stock`, `account`, `sale_stock`

## Instalación
1. Clonar dentro del `addons_path` del servidor Odoo 19 junto con los demás módulos `biotex_*`.
2. Actualizar lista de aplicaciones e instalar `biotex_remision`.
